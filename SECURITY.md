# Security Policy for apate_python_plus

## Supported Versions

We actively maintain security updates for the latest release versions of **apate_python_plus**.  
Please ensure you are using the latest version before reporting a security issue.

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **report it privately** to the maintainers.

- **Email:** jerryxu1949@163.com  
- Subject: `[Security] Vulnerability Report in apate_python_plus`

Please include:

- Description of the vulnerability  
- Steps to reproduce  
- Impact assessment (if known)  
- Any suggested fixes (optional)  

Do **not** open a public GitHub issue for security vulnerabilities.

---

## Security Response Process

1. Confirm receipt of the vulnerability report within **48 hours**.  
2. Assess severity and potential impact.  
3. Collaborate with the reporter to verify the issue.  
4. Prepare a fix and update the affected version(s).  
5. Release a patched version and publicly disclose the issue responsibly.  

We aim to resolve critical vulnerabilities as quickly as possible, typically within **30 days** depending on complexity.

---

## Reporting Guidelines

When reporting a vulnerability:

- Be as detailed as possible  
- Include reproduction steps, code snippets, or test cases  
- Do not include exploit code in public communication  
- Maintain confidentiality until a fix is released  

---

## Acknowledgements

We appreciate responsible disclosure and will give proper credit to contributors who report valid security vulnerabilities.
