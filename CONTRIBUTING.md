# Contributing to apate_python_plus

Thank you for considering contributing! 🎉  
We welcome all kinds of contributions: bug reports, feature requests, documentation improvements, and code contributions.

---

## How to Contribute

### 1. Fork the Repository

Fork the repo on GitHub, then clone your fork:

```bash
git clone https://github.com/your-username/apate_python_plus.git
cd apate_python_plus
~~~

------

### 2. Create a Branch

Always create a new branch for your changes:

```bash
git checkout -b feature/your-feature-name
```

Examples:

- `feature/add-parser`
- `fix/bug-123`
- `docs/update-readme`

------

### 3. Make Your Changes

- Keep changes focused and minimal
- Follow existing code style
- Add comments if necessary
- Update documentation if applicable

------

### 4. Commit Your Changes

Use clear and meaningful commit messages:

```bash
git commit -m "feat: add new parsing logic"
```

Common prefixes:

- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `refactor:` code improvement

------

### 5. Push to Your Fork

```bash
git push origin feature/your-feature-name
```

------

### 6. Open a Pull Request

- Go to the original repository on GitHub
- Click **New Pull Request**
- Provide a clear description of your changes

------

## Reporting Issues

If you find a bug or want to request a feature:

- Check if it already exists in Issues
- Provide clear steps to reproduce
- Include logs or screenshots if helpful

------

## Code Guidelines

- Use clear and readable variable names
- Keep functions small and focused
- Follow Python best practices (PEP 8 where possible)

------

## Code of Conduct

By participating in this project, you agree to follow the [Code of Conduct](https://chatgpt.com/c/CODE_OF_CONDUCT.md).

------

## Tips

- Keep pull requests small and focused
- One feature or fix per PR
- Be respectful in discussions

Thank you for contributing ❤️
